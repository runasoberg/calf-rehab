# calf-rehab

AI-assisted calf rehab and training coaching system: Claude project docs, recovery protocols, and Notion session-logging integration.

A personal AI coaching system built on Claude for calf/gastrocnemius rehab and return-to-sport training. It combines evidence-based recovery protocols with Notion-based session logging, tracking progress from injury through return to basketball, tag rugby, and strength training.

## Repository structure

The folders follow the product process, in order.

| Folder | Purpose |
|---|---|
| [`problem_discovery/`](problem_discovery/) | What problem we are solving and for whom: problem definition, user interviews, injury research, competitive landscape. |
| [`solution_discovery/`](solution_discovery/) | Exploring ways to solve it: discovery plan, prototype prompts (Claude, Lovable, Figma Make) and the low-fidelity prototypes. |
| [`final_product/`](final_product/) | The chosen solution: specs, the built product and its documentation. |
| [`supporting_documentation/`](supporting_documentation/) | Reference material that supports all stages: the first-draft PRD, protocols, templates, decision records. |

Root files: this `README.md` (orientation for people) and [`CLAUDE.md`](CLAUDE.md) (operating instructions for Claude).

## Status

Solution discovery is in progress. Five low-fidelity directions exist as HTML prototypes in `solution_discovery/prototypes/`, with a Lovable build in progress ([preview](https://id-preview--2685ccc9-f51e-4cde-9287-ff774bcc672f.lovable.app)) and a Figma Make build (five directions of its own) published at https://phys-prototypes.figma.site/. The interface decision is still open (PRD decision log, item 2). See `supporting_documentation/claude_1st_draft_PRD.md`.
